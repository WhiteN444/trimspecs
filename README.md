# TrimSpecs — Vehicle Factory Specs Reference

A free reference for looking up **factory vehicle specifications per trim** — tire sizes, engine oil capacity and type, and towing capacity — organized by year, make, model, and trim.

🔗 **Website:** [trimspecs.com](https://trimspecs.com)

## Why per-trim matters

The same model year often ships with different specs depending on the trim and engine. A base trim and a top trim of the same truck can run different wheels, different oil requirements, and very different tow ratings. Generic answers get this wrong — TrimSpecs breaks every spec down per trim, the way it appears on your door-jamb placard.

- **Towing capacity** — maximum tow rating per configuration, with package requirements
